# 赛博小强 CyberRoach

桌面蟑螂宠物: 鼠标变蟑螂、小强满桌爬、按温湿度成长繁殖、拖鞋模式拍死它。

## 下载 (不想装 Python 看这里)

到 [Releases](../../releases) 页面下载 `CyberRoach.exe` (单文件, 双击即玩,
无需安装 Python 或任何依赖)。

## 从源码运行

需要 Python 3.10+, 安装依赖后运行 main.py:

```
pip install pygame pywin32 psutil pystray ani_file pillow numpy
python main.py
```

快捷键配置: 复制 `config.example.json` 为 `config.json` 后自行修改。

## 运行

- **exe**: 双击 `CyberRoach.exe` 即可 (Releases 下载)
- **源码**: 双击 `启动小强.bat`, 或 `python main.py`

## 温度与开机自启

- 托盘右键有 **开机自启** 开关(写 HKCU Run 注册表, 不需要管理员)
- CPU 温度采用**负载驱动的模拟值**(动态变化): 负载越高温度越高,
  小强繁殖越快。真实温度方案(LibreHardwareMonitor, 需管理员+内核驱动)
  因稳定性问题已禁用(`main.py` 里 `USE_REAL_TEMP = False`)
- 开机自启指向: 打包后用 exe 自身, 源码运行用 pythonw.exe

## 玩法

- **鼠标就是一只蟑螂**(动态光标, 腿会动), 蟑螂靠近光标会吓得逃跑
- 桌面上的小强会爬行、试探、冲刺、歇脚, 全程点击穿透不挡操作
  (唯独点在小强身上会把它吓跑)
- **繁殖**: 成虫按湿度怀孕 -> 拖着卵鞘跑 -> 孕满落卵, 卵孵化成若虫长大;
  CPU 温度/负载越高 = "虚拟湿度"越高, 长得越快、产卵越勤 (上限 20 只)
- **拖鞋模式**: 光标变拖鞋, 点到小强/卵直接拍扁, "啪"一声溅射动画;
  2 秒内连拍出 combo, 屏幕飘"连杀 xN"; 拍死怀孕母蠊会爆出 2-3 只
  小若虫四散奔逃
- **喂食**: 按 **Ctrl+Q**(默认, 可自定义) 或托盘"扔面包屑", 在鼠标处
  掉一块面包屑; 480px 内的小强会闻香赶来围着一圈啃, 吃饱(satiety>0.25)的
  成长速度 x3、怀孕率 x2.2、孵化 x2; 面包屑 90 秒风干, 最多同时 8 块
- **自定义快捷键**: 托盘"自定义快捷键..."打开 `config.json`, 把
  `"hotkey": "ctrl+q"` 改成想要的组合(如 `"ctrl+alt+f"`、`"ctrl+shift+1"`)
  保存即可, **1 秒内自动生效**无需重启; 修饰键支持 ctrl/alt/shift/win,
  主键支持字母/数字/F1-F24/方向键等
- 托盘图标(小强)右键: 拖鞋模式 / 扔面包屑 / 自定义快捷键 / 蟑螂光标开关 /
  还原默认光标 / 退出, 悬停可看 CPU 温度、湿度、数量、面包屑数、拍死数、
  最高连杀
- ESC 或托盘"退出"结束程序, 光标自动还原

## 素材与结构

- **写实版素材**（默认）: AI 生成照片级蟑螂/拖鞋, `process_realistic.py` 自动
  抠图(洪泛去白+封闭白区清除) -> PCA 主轴摆正 -> 红色复眼定位头朝向 ->
  4 帧微摆动动画; 原图在 `assets/raw/`
- `generate_sprites.py` 程序化绘制蟑螂(兜底素材) / 卵鞘 / 拍扁图
- `make_cursors.py` 用 ani_file 合成 .ani 动态光标
- `chunk.py` Python 3.13 缺失的 stdlib chunk 模块垫片
- `main.py` 主程序: 透明置顶窗口(colorkey 点击穿透) + 行为 AI + 生态模拟

## 已知边界

- 机箱没有真实湿度传感器, 湿度由模拟温度+负载虚拟合成
- 程序异常被强杀可能导致光标停留在蟑螂状态: 用托盘"还原默认光标",
  或注销重登即可恢复
